# Criando Uma IA

Projeto desenvolvido em Python com o objetivo de estudar e explorar conceitos de Inteligência Artificial, programação e desenvolvimento de aplicações interativas.

## Sobre o projeto

Este repositório reúne estudos, experimentos e atividades práticas relacionadas ao desenvolvimento de soluções utilizando Python.

O projeto também explora a criação de interfaces interativas utilizando Gradio.

## Tecnologias utilizadas

- Python
- Gradio
- Git
- GitHub

## Estrutura do projeto

```text
Criando-Uma-IA/
│
├── Criando-Uma-IA/
├── Fundamentos/
├── Gradio/
│
└── .gitignore
```

## Interface interativa

O projeto utiliza a biblioteca Gradio, que permite desenvolver interfaces para aplicações Python de maneira simples e interativa.

## Objetivos de aprendizagem

- Desenvolver conhecimentos em Python.
- Estudar fundamentos de Inteligência Artificial.
- Explorar bibliotecas e ferramentas.
- Criar aplicações interativas.
- Praticar versionamento de código com Git e GitHub.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Douglas2022/Criando-Uma-IA.git
```

2. Entre na pasta:

```bash
cd Criando-Uma-IA
```

3. Instale as dependências, caso exista um arquivo `requirements.txt`:

```bash
pip install -r requirements.txt
```

4. Execute o arquivo Python correspondente ao projeto.
