# Criando uma IA 

Projeto desenvolvido em Python com o objetivo de estudar e construir uma aplicação de Inteligência Artificial.

##  Tecnologias

- Python
- Pandas
- Ambiente virtual (venv)
- Git e GitHub

##  Estrutura do projeto

```text
Criando-Uma-IA/
├── venv/
├── README.md
├── requirements.txt
└── soma.py
```

##  Como executar

Clone o projeto:

```bash
git clone git@github.com:Douglas2022/Criando-Uma-IA.git
```

Entre na pasta:

```bash
cd Criando-Uma-IA
```

Crie o ambiente virtual:

```bash
python -m venv venv
```

Ative o ambiente virtual no Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

Instale as dependências:

```powershell
pip install -r requirements.txt
```

Este projeto faz parte dos meus estudos de programação e Inteligência Artificial, utilizando Python para desenvolver e testar diferentes funcionalidades.
